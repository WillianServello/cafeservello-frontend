# ☕ Café Servello

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **.NET 10**
- **Blazor WebAssembly**
- **C#**
- **HTML5**
- **CSS3**
- **Bootstrap Icons**
- **Figma** (prototipação e design da interface)

---

## 🏛️ Arquitetura

O frontend foi desenvolvido utilizando **Blazor WebAssembly**, seguindo uma estrutura modular para facilitar a manutenção e a escalabilidade do projeto.

A solução é composta por dois projetos:

### 📦 CafeServello.Client

Responsável por iniciar a aplicação, realizar as configurações do Blazor WebAssembly e gerenciar a execução do frontend.

### 🎨 CafeServello.UI

Biblioteca responsável por toda a interface da aplicação.

Neste projeto estão organizados:

- Componentes reutilizáveis;
- Páginas;
- Layouts;
- Serviços da interface;
- Estilos (CSS);
- Recursos visuais.

Essa separação permite manter o código mais organizado, limpo e de fácil manutenção, além de facilitar a reutilização de componentes em futuros projetos.

---

## 🎨 Design

Todo o design da aplicação foi planejado e prototipado no **Figma**, permitindo definir a identidade visual, a experiência do usuário (UX) e a interface (UI) antes do desenvolvimento.

O protótipo serviu como base para garantir consistência visual entre todas as telas da aplicação e facilitar futuras evoluções do projeto.
